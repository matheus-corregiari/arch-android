# Changelog - 1.2.0

**Status:** Draft, based on the current diff against `master`.

## Build and tooling

- Aligned Kotlin, Android Gradle Plugin, Detekt, Kover, and Gradle wrapper with the current Arch
  tooling baseline.
- Removed Dependabot in favor of the repository release-flow automation.
- CI now validates release and hotfix branches consistently across build, lint, test, coverage, and
  documentation workflows.
- Centralized the shared Kover configuration in build logic and removed module-specific coverage
  exclusions.

## Documentation

- Documented the supported Kotlin, Gradle, JDK, and Android SDK versions.
