# 1.4.0

Planned release based on tag `1.3.2`.

## Changes

- Explain Android utility ownership, Views lifecycle, Compose/KMP boundaries and concrete
  criteria for local SharedPreferences or Arch Storage.
- Add lifecycle, View state, RecyclerView and preference recipes, compiled and exercised
  by the existing Android host test and lint gates.
- Check recipe snippets against compiled examples in the existing Python CI checks.
- Fix missing parent IDs in View delegates: optional lookup returns null and required lookup
  reports the existing descriptive IllegalStateException instead of NullPointerException.
- Correct initialization guidance and classify published `1.3.2` as a tagged release.

## Compatibility

Public signatures and dependencies are unchanged. Android minimum SDK remains 20.
Android host behavior is covered; this library has no Apple/browser or shared targets.
