# 1.3.2

Maintenance changes based on tag `1.3.1`.

## Changes

- Update Gradle to 9.8.0, AGP to 9.4.1 and Kover to 0.9.11.
- Compile against finalized Android SDK 37.2; retain minimum SDK 20 and Build Tools 37.0.0.
- Centralize Android platform defaults in the library convention and enable Kotlin progressive mode.
- Use Kotlin `TimeSource.Monotonic` for cache expiration, preserving duration precision and avoiding wall-clock changes.
- Scan every KMP Kotlin source set with Detekt.
- Apply module coverage explicitly and keep Dokka independent of Kover and JaCoCo.

- Update Android SDK setup to `android-actions/setup-android@v4` (Node 24 and the maintained command-line tools provided by the action), explicitly installing `platform-tools` instead of the unavailable legacy `tools` package.

- Remove unused AtomicFU/Compose properties and the obsolete Android source-set layout flag.
- Replace deprecated Gradle `extra` delegation in build settings.
- Apply one generated-class filter to module reports and root coverage aggregation, including HTML, XML and verification.
- Disable Codecov report discovery so only `build/reports/kover/report.xml` is uploaded; module reports cannot reintroduce excluded classes.
- Exclude only Android-generated `BuildConfig`, `R` and nested `R` classes; retain handwritten code and existing coverage floors.
- Configure Android test JVM access required by Robolectric 4.17 on JDK 21.
- Add persistence recreation, default-value and blank-value removal tests, preserving the existing coverage floors.
- Update the GitHub App token action to v3 (Node 24 on hosted runners).
- Use this versioned changelog directly for the GitHub Release, without a duplicate root notes file.
- Repair ecosystem links and document AndroidX Security deprecation and application-owned target SDK.
- Document coverage scope, local commands and the audited dependency versions.
- Update MkDocs Material from 9.7.6 to 9.7.7.
- Verify the Gradle 9.8.0 distribution with its official SHA-256 checksum.

## Compatibility

No public API changes. Existing minimum Android SDK and KMP targets remain unchanged.
Coverage measures Android host tests; this library exposes only the Android KMP target.

Dependencies on other Arch repositories use versions available in Maven Central, rather than unpublished patch candidates.
